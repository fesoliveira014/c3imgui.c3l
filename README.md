# c3imgui.c3l

Dear ImGui bindings for C3. Three modules:

- `imgui` — core API (windows, widgets, drawing, fonts, tables, drag/drop, etc.)
- `imgui::sdl` — SDL3 platform backend
- `imgui::gl` — OpenGL3 render backend

This directory is a self-contained C3 library package (`.c3l`) — list it as a `c3imgui` dependency in your project's `project.json` and add this repo's path to `dependency-search-paths`.

The `imgui.c3i`, `imgui_sdl.c3i`, `imgui_gl.c3i` files are generated by `scripts/translate.py` from `dear_bindings` JSON metadata. Do not hand-edit. Re-run `../scripts/bootstrap.sh` after changing the symbol allowlists in `scripts/*_imgui.json` (and the matching `*_sdl.json` / `*_gl.json`).

See the repository root `README.md` for the full feature list, quickstart, and consumer code examples.
